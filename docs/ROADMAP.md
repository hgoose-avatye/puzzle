# 개발·폴리싱 계획 (2026-10-30)

[경쟁작 비교](competitor-comparison.md), [현황](STATUS.md), [폴리싱 목록](POLISH.md)을 바탕으로, 무엇을 어떤 순서로 할지 정리했다. 사용자가 정한 우선순위(① 레벨 디자인 → ② 화면 → ③ 디자인 에셋·맵 → ④ 폴리싱·QA)를 따르되, 비교에서 드러난 큰 빈틈을 단계마다 끼워 넣었다.

## 방향 한 줄

**두 게임처럼 콘텐츠와 모드를 늘리기보다, 40~60대가 "설명 없이 바로 이해되고, 실수해도 편안한" 경험을 먼저 완성한다.** 차별점(동물 크기 = 조각, 색 문, 판이 꼬이지 않음)은 지키고, 다른 게임에서 빌려 온 요소는 우리 요소로 바꾼다.

## 단계

### 1단계. 처음 10분 경험 완성 (지금 → 약 1~2주)

비교에서 가장 큰 차이가 "직접 해 보는 안내"와 기본 화면이었다. 새 이용자가 처음 만나는 부분부터 메운다.

| 할 일 | 내용 | 관련 |
|---|---|---|
| 첫 실행 튜토리얼 | 레벨 1에서 손가락 아이콘으로 "누르면 문으로 나가요", 막힌 친구 눌러 보기까지 안내 | 비교 3-1 |
| 새 규칙 튜토리얼 | 요소가 처음 나오는 레벨에서 그림 카드 + 첫 수를 손가락으로 짚어 직접 해 보기(화살표, 하트, 상자, 긴 동물, 열쇠, 잠, 폭탄) | 비교 3-1 |
| 손으로 설계한 가르침 레벨 | 요소마다 처음 2~3개 레벨을 직접 설계. 레벨 데이터 파일로 생성 레벨을 덮어쓰는 구조와 간단한 확인 도구 | 비교 3-3, 폴리싱 L7 |
| 메인 화면, 일시정지·설정 | 이어 하기, 현재 위치, 효과음·볼륨·진동, 튜토리얼 다시 보기 | 비교 3-2 |
| 로딩 화면, 정보·라이선스 | | STATUS 3 |

**완료 기준**: 처음 해 보는 사람이 글을 읽지 않고 레벨 1~12를 깬다. 방향을 몰라 하트를 잃는 일이 직접 해 봤을 때 거의 없다.

### 2단계. 레벨 디자인 심화 (약 2주)

| 할 일 | 내용 | 관련 |
|---|---|---|
| 빌려 온 요소 교체 | 폭탄, 자는 동물을 우리 요소로. 후보: **가족 줄**(엄마가 나가면 아기들이 따라 나감, 막판 해소감도 해결), **번호 문**(문 번호 순서대로 열림, 열쇠·잠금 대체) | 비교 5, 설계 6.2 |
| 막판 해소감 | 가족 줄을 마지막 레벨에 써서 "한꺼번에 쏟아지는" 장면 | 폴리싱 L6 |
| 레벨 역할 확장 | "까다로움"(요소 조합으로 생각이 필요한 레벨) 추가 | 비교 3-9 |
| 직접 플레이로 난이도 조정 | 하트 3개·동물 60%·화살표 50%를 직접 해 보고 상수 조정. 가상 플레이어의 실수 가정도 맞춤 | 폴리싱 L9, D3, D5 |
| 출시 범위 확정 | 1차 90레벨(1~3챕터) vs 180레벨 | 설계 6.1 |

**완료 기준**: 다른 게임에서 빌려 온 특색 요소가 없다. 직접 해 봐서 일반·어려움·마지막 레벨의 체감이 의도와 맞는다.

### 3단계. 디자인 에셋·맵 (약 2~3주, 확보 방식에 따라 다름)

| 할 일 | 내용 | 관련 |
|---|---|---|
| 에셋 확보 방식 결정 | 구매·무료 에셋 / 아티스트 제작 / 코드로 계속 다듬기 | 폴리싱 M1 |
| 장면 품질 | 소품·건물 교체, 장면 밀도 맞추기, 큰 소품이 잘리는 문제 | 폴리싱 M1, M2, M5 |
| 물과 빛 | 물결, 반짝임, 레퍼런스의 바닥 화살표·빛나는 출구 문 | 폴리싱 M3, M6 |
| 캐릭터 다듬기 | 선택 시 빛남, 막힘 시 고개 젓기·말풍선(레퍼런스 05) | 폴리싱 F4 |

**완료 기준**: 레퍼런스 03, 04, 08과 나란히 놓았을 때 같은 게임으로 보인다.

### 4단계. 출시 준비와 QA (약 1~2주)

| 할 일 | 내용 | 관련 |
|---|---|---|
| 광고 연결 | 회사 SDK, 실패 후 이어 하기, 힌트 정책 | STATUS 3 |
| 배포 | 웹 링크 / 앱스토어 결정 후 배포 | STATUS 5 |
| 실제 기기 QA | 효과음 볼륨, 글자 크기, 1칸 동물 탭 정확도, 저사양 폰 프레임, 색각 접근성, 방향 표시 가려짐 | 폴리싱 S1, A1~A4, T1, F1, F8 |
| 기술 정리 | 번들 크기, 테스트용 연결점 제거, 메모리 | 폴리싱 T2, T4, T5 |
| 라이선스·법적 검토 | 효과음, 아트 레퍼런스, 기존 게임과 비슷한 부분 | 폴리싱 C5 |

**완료 기준**: 폴리싱 목록의 "상" 항목이 모두 닫혔다.

### 5단계. 출시 후 (유지·확장)

| 할 일 | 내용 | 관련 |
|---|---|---|
| 일일 레벨, 도전 레벨 | 매일 오는 이유, 잘하는 사람을 위한 큰 판 | 비교 3-7 |
| 움직이는 요소 | 시간에 따라 열렸다 닫히는 문 등. 실수해도 꼬이지 않는 범위에서 | 비교 3-6 |
| 메타 | 구출한 동물 도감 → 동물 마을 | 비교 3-8, 설계 3.4 |
| 시즌 이벤트, 챕터 추가 | 크리스마스·설날 스테이지, 세계 도시 챕터 | 설계 6.1 |

## 폴리싱을 어떻게 진행할까

- [POLISH.md](POLISH.md)는 단계별로 나눠 처리한다. 레벨 디자인(L)은 2단계, 맵(M)은 3단계, 연출·소리·접근성·성능(F, S, A, T)은 4단계에 몰아서 실제 기기로 확인한다.
- **매 단계 끝에 직접 플레이 시간**을 둔다. 사람 플레이테스트를 못 하는 대신, 단계마다 직접 20~30분 플레이하고 느낀 점을 POLISH.md에 바로 적는다.
- 가상 플레이어 보고서(`npx tsx scripts/sim-report.ts`)는 레벨을 바꿀 때마다 다시 돌려 난이도가 튀지 않는지 본다.

## 결정이 필요한 것 (단계 순)

| 언제 | 결정 | 영향 |
|---|---|---|
| 1단계 전 | 튜토리얼 형식: 손가락 안내 + 그림 카드로 갈지 | 1단계 범위 |
| 2단계 전 | 폭탄·자는 동물을 가족 줄·번호 문으로 바꿀지 | 생성기, 레벨 전체 재생성 |
| 2단계 | 출시 범위(90 / 180레벨) | 다듬을 레벨 수 |
| 3단계 전 | 에셋 확보 방식 | 3단계 기간과 비용 |
| 4단계 전 | 광고 정책(힌트·이어 하기), 배포 형태 | 실패 화면, 수익 |
