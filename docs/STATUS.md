동물 구출 퍼즐(가제)의 현재 상태다. 무엇이 됐고, 무엇을 더 만들어야 하고, 무엇을 다듬어야 하는지 한곳에 모았다. 규칙과 기획의 근거는 [설계 문서](superpowers/specs/2026-10-29-puzzle-core-generator-design.md)에 있다.

### 실행

- 게임: `npm run dev:game` 후 http://localhost:5200
  - `?level=N`: 해당 레벨 바로 열기

  - `?demo=1`: 동물 종류 확인용 장면
- 레벨 확인용 뷰어: `npm run dev`
- 테스트: `npm test`
- 가상 플레이어 보고서: `npx tsx scripts/sim-report.ts` (약 40초, 결과는 `docs/sim/sim-report.json`)
- 레벨 씨앗 다시 고르기: `npx tsx scripts/pick-seeds.ts` (약 5분). 생성기나 곡선을 바꾸면 반드시 다시 돌린다.

## 2. 완료된 기능

### 퍼즐 규칙과 레벨
- **순수 제거형 규칙.** 탭하면 바라보는 방향으로 나가고, 길이 막혀 있으면 움직이지 않는다.
- 동물 크기는 1·2·3칸 이상이다. 한 칸 동물은 방향을 따로 가진다.
- **방향 타일(화살표):** 지나가면 꺾이고, 마주 보면 벽이 된다.
- **고정 장애물(덤불).**
- **열쇠와 잠금, 자는 동물, 시한폭탄.** 폭탄은 탭 수 기준이라 시간 압박이 없다.
- **하트:** 막힌 동물을 탭할 때마다 하나씩 줄고, 0이 되면 실패다.
- **풀이기와 난이도 지표:** 라운드 수, 처음부터 나갈 수 있는 비율, 평균 막힘 수 등.
- **레벨 생성기:** 거꾸로 배치하는 방식이라 항상 풀 수 있다. 지표 목표 구간에 맞는 레벨만 고른다.
- **180레벨 곡선:** 6챕터 × 30레벨. 레벨마다 입문·쉬어가기·보통·어려움·마지막 역할이 있다.
  - 챕터마다 새 요소가 하나씩 나온다: 1챕터 화살표, 2챕터 긴 동물, 3챕터 열쇠, 4챕터 자는 동물, 5챕터 폭탄, 6챕터 종합.
- **이번에 고친 것** (`feat/sim-player`)
  - 폭탄이 여러 개인 레벨 중 일부(142, 148)를 어떤 순서로 플레이해도 깰 수 없던 버그. 이제 모든 폭탄 레벨을 깰 수 있는지 테스트로 확인한다.
  - 하트: 1챕터에서는 레벨 7부터 나오고, 7~9는 5개로 시작한다. 이후 개수는 동물 수에 맞춘다(20마리 이하 3개, 25마리 이하 4개, 그보다 많으면 5개).
  - 레벨마다 후보 10개 중 난이도 흐름에 맞는 것을 골라 둔다(`src/curve/seeds.json`).

### 게임 화면 (Three.js)
- 아트 레퍼런스를 바탕으로 블록 동물 12종을 만들었다. 펭귄, 병아리, 앵무새, 소, 돼지, 여우, 호랑이, 허스키, 뱀, 애벌레, 닥스훈트, 악어.
- 출구 문은 동물과 같은 색이다. 꾹 누르면 나갈 길(화살표)이 보인다.
- 나가는 길은 코너가 둥글게 이어지고, 몸이 마디마디 따라 꺾인다.
- 연출: 달릴 때 먼지, 구출 폭죽, 막힘 별, 클리어 색종이, 자는 동물의 Zzz, 열쇠·자물쇠·폭탄 표시.
- 첫 등장 요소마다 팁 팝업이 뜨고, 진행 상황이 저장된다.
- 동시 이동 (`feat/game-traffic-sound`)
  - 먼저 보낸 동물이 우선이다. 뒤 동물은 갈 수 있는 데까지 가서 기다리다가 길이 열리면 스스로 다시 출발한다. 서로 몸을 통과하지 않는다.
  - 기다리기 시작할 때 노란 `!`, 기다리는 동안 `…`가 뜬다.

### 소리
- 효과음 8종: 선택, 이동, 벽, 충돌, 구출, 클리어, 게임오버, 이동 완료.
  - 이동 완료음은 쓸 상황이 없다. 이 게임의 동물은 보드 밖으로 나가며 멈추지 않는다.
- 겹침 방지: 효과음 간 우선순위, 동시 재생 최대 4개, 같은 소리 반복 간격 제한.
- 음소거 버튼(설정 저장됨). 음원은 페이지를 열 때 미리 불러온다.
- 출처와 라이선스 메모: [sound-credits.md](sound-credits.md)

### 도구
- 레벨 뷰어: 레벨 번호로 플레이, 시도 기록, 기록 복사.
- 가상 플레이어 시뮬레이션: 꼼꼼함·보통·성급함 세 유형. 레벨끼리 비교하는 용도다.
- 광고 목업 인터페이스(`src/ads`). 게임에는 아직 연결하지 않았다.

## 3. 구현해야 할 것

### 출시 전 꼭 필요
1. **배포.** 휴대폰에서 링크로 열 수 있게 한다(정적 호스팅). 앱스토어 출시 여부는 아직 정하지 않았다.
2. **레벨 선택과 진행 화면.** 지금은 "다음" 버튼으로 아무 레벨이나 넘어갈 수 있다(테스트용).
3. **광고 연결.** 회사 SDK를 연동하고, 노출 시점과 보상 구조를 정한다(클리어 보상, 실패 시 하트 충전 등).
4. **힌트.** 설계 문서의 "스마트 힌트". 나갈 수 있는 동물 하나를 살짝 보여 주는 방식이 유력하다.
5. **실패 후 흐름.** 하트가 다 떨어졌을 때 다시 하기, 광고 보고 이어 하기.
6. **라이선스 확인.** Mixkit, Pixabay 효과음 라이선스 원문과 아트 레퍼런스 이미지(ChatGPT 생성)의 상업 사용 조건.

### 콘텐츠와 메타 (설계 문서 3.4절, 6.1절)
- 챕터별 배경과 테마: 동물 마을, 숲, 해적섬, 정글, 유령 성, 겨울.
- 세계 일주 월드맵. 에셋 후보는 설계 문서 3.7절에 있다.
- 구출한 동물이 사는 동물 마을(메타).
- 시즌 이벤트, 일일 레벨.
- 꺾여서 놓인 동물(뱀, 애벌레)의 생성기. 지금은 2챕터를 긴 직선 동물로 대신하고 있다.
- 마지막 레벨의 "막판에 한꺼번에 쏟아지는 해소감". 지금 생성기 구조로는 이런 레벨을 만들 수 없다.

### 결정 후 구현
- **임시 요소 교체.** 열쇠, 자는 동물, 폭탄, 하트는 다른 게임에서 빌려 온 임시 요소다. 우리 요소(가족 줄, 번호 문)로 바꿀지 정해야 한다. 원래는 플레이테스트 뒤에 정하기로 했지만 테스트를 못 하므로 직접 판단해야 한다.
- **막힌 동물의 이동 방식.** 지금은 제자리에서 흔들리고 하트가 준다. "막힌 곳까지 이동"(부딪힘 변주)은 퍼즐 규칙, 생성기, 풀이기가 모두 바뀌는 큰 변경이다(설계 문서 3.5절).

## 4. 폴리싱해야 할 것

### 난이도
- **5·6챕터(폭탄)의 들쭉날쭉함.** 레벨을 고를 때 쓰는 점수가 실수 횟수만 세고 폭탄 실패는 반영하지 않는다. 그래서 인접 레벨 간 실패율 차이가 평균 18%p로 남아 있다(1~4챕터는 약 6%p). 점수에 실패율을 넣어 씨앗을 다시 고르면 된다.
- **어려운 레벨이 주변보다 덜 어려운 경우.** 예: 1챕터 레벨 20(50%)이 레벨 21(67%)보다 쉽다. 챕터 후반의 보통 레벨이 너무 올라와 있다.
- **절대 난이도가 목표보다 높을 수 있다.** 설계 문서의 목표는 보통 레벨 첫 시도 클리어율 80~90%다. 가상의 보통 플레이어는 1챕터 후반 보통 레벨에서 60% 안팎으로 실패한다. 이 숫자는 실수 확률 가정에 좌우되므로 실제 사람 데이터 없이는 확정할 수 없다. 레벨 간 비교는 믿을 만하고, 절대값은 참고만 한다.
- 하트 개수(3/4/5)와 레벨 7~9의 하트 5개는 후보값이다.

### 화면과 연출
- `!`와 `…`의 크기와 위치를 실제 휴대폰에서 확인해야 한다. 지금은 헤드리스 브라우저 스크린샷으로만 봤다.
- 실제 속도에서는 대기가 약 0.4초라 `…`가 거의 안 보인다. 의도대로인지 확인이 필요하다.
- 아트 레퍼런스에 있는 선택 시 빛나는 효과, 막힘 시 말풍선은 아직 없다.
- 색각 이상 사용자를 위한 확인이 필요하다. 출구 문 색에 많이 의존한다.
- 햅틱(진동)이 없다. 웹에서는 지원이 제한적이다.

### 소리
- 볼륨 8종의 귀 테스트와 조정. 지금은 기획서의 초기값 그대로다.
- 받은 Mixkit 파일은 미리듣기용 128kbps다. 고음질 원본으로 바꿀지 정한다.

### 기술
- 게임 번들이 584kB(gzip 151kB)라 빌드 경고가 난다. Three.js 분할이나 필요한 부분만 가져오기를 검토한다.
- favicon이 없어서 404가 난다.
- 테스트용 기능 정리: 데모 URL, `window.__game` 테스트 연결점, `__runSpeed`. 출시 빌드에서 뺄지 정한다.
- 저사양 휴대폰에서 성능 확인. 동물 28마리와 이펙트가 동시에 나오는 경우.

## 6. 알려진 위험

- **실제 사람의 체감 난이도를 확인한 적이 없다.** 가상 플레이어는 레벨 간 비교와 버그 찾기에는 유용하지만, 사람의 체감을 대신하지 못한다.
- 웹 오디오 지연과 햅틱은 네이티브 앱보다 불리하다.
- 게임 규칙 자체는 다른 게임과 비슷하다(Arrows, Escape Sheep, Parking Jam). 아트와 캐릭터는 새로 만들었지만 출시 전 전문가 확인이 필요하다(설계 문서 6.2절).
