# Escape Sheep · Parking Jam 3D 비교 (2026-10-30)

우리 게임(동물 구출 퍼즐, 가제)을 Escape Sheep, Parking Jam 3D와 나란히 놓고 부족한 점과 차별점을 정리했다.

## 0. 근거와 한계

| 표시 | 뜻 |
|---|---|
| **[데이터]** | 앱 파일에서 직접 확인. Parking Jam 3D는 레벨 1,748개를 디코딩한 [분석 문서](parking-jam-3d-analysis.md), Escape Sheep은 앱 내 튜토리얼 문구와 레벨 100개를 본 [설계 문서 3.5절](superpowers/specs/2026-10-29-puzzle-core-generator-design.md) |
| **[이름]** | 앱 안의 클래스·파일 이름으로 짐작. 실제 동작은 확인하지 못함 |
| **[장르 추정]** | 이 장르 게임에서 흔히 보이는 방식. 이 두 게임에서 직접 확인하지 않음 |

- 두 게임 모두 실행 파일이 암호화되어 있어 코드를 읽지 못했다.
- **직접 플레이해서 본 적이 없다.** 그래서 UI·UX 비교의 상당 부분은 [장르 추정]이다. 출시 전에 두 게임을 실제로 해 보며 이 문서의 [장르 추정] 칸을 확인하는 것을 권한다.

## 1. 두 게임의 공통 규칙

두 게임과 우리 게임은 모두 **"막힌 것을 순서대로 빼내는" 퍼즐**이다. 공통 뼈대는 다음과 같다.

| 공통 규칙 | Escape Sheep | Parking Jam 3D | 우리 게임 |
|---|---|---|---|
| **한 번 탭으로 조작**: 끌기 없이, 누르면 정해진 방향으로 움직인다 | 양을 누르면 바라보는 방향으로 달림 [데이터] | 차를 누르면 움직여 주차장을 빠져나감 [데이터] | 같음 |
| **격자 판 위의 조각** | 격자 [데이터] | 정수 격자, 차는 2×3~2×5 직사각형 [데이터] | 격자, 동물 1~3칸 |
| **길이 막히면 못 나간다**: 이동 경로에 다른 조각이나 벽이 있으면 막힘 | 다른 양·울타리 [데이터] | 다른 차·벽 [데이터] | 같음 |
| **판 밖으로 나가면 사라지고, 모두 내보내면 클리어** | [데이터] | [데이터] (일반 레벨 기준) | 같음 |
| **실수에 한도가 있다** | 하트, 일부 스테이지는 탭 수·시간 제한 [데이터] | 이동 횟수 제한, 추가 목숨 [데이터] | 하트 3개 |
| **판 위에 고정 장애물** | 울타리 [데이터] | 벽, 공사장 [데이터] | 부서지는 상자 |
| **조각마다 특수 성질을 붙여 변주** | 시한폭탄, 자는 동물, 병아리, 코끼리, 매력양 [데이터] | 열쇠·잠금, 체력 차량, 할머니, 움직이는 장애물, 헬리패드, 맨홀 [데이터] | 열쇠·잠금, 잠, 폭탄 |
| **난이도는 조각 수보다 제약과 특수 요소로 올린다** | 레벨 역할(보통·어려움·까다로움·극한·쉬어가기), 사람 클리어율로 관리 [데이터] | 일반 레벨은 차 9대 안팎으로 평평하고, 이동 제한과 특수 오브젝트로 난이도를 올림 [데이터] | 역할 체계, 가상 플레이어 실패율 |
| **레벨은 풀이기로 검증한다** | 사람 클리어율 시뮬레이션 [데이터] | 레벨 생성기·풀이기·에디터 [이름] | 풀이기, 전수 탐색, 가상 플레이어 |

**가장 큰 규칙 차이**는 Escape Sheep의 "부딪힘"이다. 양은 막히면 **그 자리에 멈춰서 판이 바뀐다.** 그래서 양을 움직여 다른 양의 길을 만들 수 있고, 풀 수 없는 상태(소프트락)도 생긴다. Parking Jam과 우리 게임은 막히면 움직이지 않는 순수 제거형이다.

## 3. 우리에게 부족한 것 (우선순위 순)

### 출시 전에 메워야 할 것
1. **직접 해 보는 튜토리얼**: 글자 팝업 대신, 새 요소가 나오는 첫 레벨에서 손가락으로 짚어 한 번 해 보게 한다.
2. **메인 화면, 설정, 실패 후 이어 하기**: 두 게임 모두 있는 기본 화면이다.
3. **손으로 설계한 핵심 레벨**: 최소한 각 요소를 가르치는 첫 레벨들. Parking Jam도 핵심 레벨은 사람이 만든다.
4. **아트 품질**: 장면 소품과 건물이 레퍼런스 수준에 못 미친다.
5. **콘텐츠 양**: 180레벨은 한 달 유지선의 최소치로 추정한 숫자다(설계 문서 6.1). 두 게임은 이보다 훨씬 많다.

### 출시 후 순차로
6. **움직이는 요소**: 시간에 따라 변하는 장애물(열렸다 닫히는 문 등). 지금 요소는 모두 정적이다.
7. **도전 레벨, 일일 레벨**: 잘하는 사람과 매일 오는 사람을 위한 별도 콘텐츠.
8. **메타(동물 도감, 동물 마을), 시즌 이벤트**: 장기 유지 장치.
9. **"까다로움·극한" 역할**: 지금은 어려움·마지막뿐이다.

### 일부러 하지 않는 것 (타깃에 맞춘 선택)
- **시간 제한**: 40~60대에게 압박이 크다.
- **부딪혀 판이 꼬이는 규칙**: 실수해도 판이 꼬이지 않는 안정감이 우리 차별점이다. 기획 문서는 후반 변주로만 검토한다.

## 4. 우리 게임만의 것 (차별점)

| 차별점 | 비고 |
|---|---|
| 동물 체형이 곧 조각 크기(1칸 새, 2칸 네발짐승, 3칸 긴 동물) | 두 게임은 같은 모양의 조각(양, 직사각형 차) |
| 동물과 같은 색의 출구 문 | 어디로 나가는지 한눈에 보임 |
| 세계 일주 지역 × 스테이지 테마, 지역마다 다른 판 바닥과 판 모양 | |
| 모든 요소가 퍼즐에 의미 있게 들어가도록 생성기가 보장하고, 출시 레벨을 테스트로 검사 | |
| 여러 마리를 동시에 보내면 앞 동물을 기다렸다가 자동으로 다시 출발 | 두 게임은 확인 못 함 |
| 실수해도 판이 꼬이지 않고, 힌트가 늘 다음 수를 알려 줌 | |

## 5. 다른 게임과 겹치는 요소 (설계 문서 6.2와 같은 내용)

| 요소 | 출처 | 상태 |
|---|---|---|
| 시한폭탄, 자는 동물, 하트, 방향 타일(화살표), 레벨 역할 체계 | Escape Sheep | 사용 중. 기획상 "시험 후 교체 검토" 대상 |
| 열쇠·잠금 | Parking Jam 3D | 사용 중. 번호 문으로 대체 후보 |
| 부서지는 상자 | 우리가 새로 만든 규칙 | 사용 중 |

규칙 자체는 장르에서 흔히 공유되지만, 특색이 강한 요소(폭탄, 자는 동물)는 우리 요소(가족 줄, 번호 문)로 바꾸는 것을 권한다. 법적 판단은 출시 전에 전문가에게 확인받는다.
