# 폭탄 규칙 R3 전후 가상 플레이어 보고서 비교 (2026-10-30)

[sim-report.json](sim-report.json)을 R3 규칙(폭탄 숫자는 나가는 탭에만 줄어듦, [rules.md](../rules.md) 11장)으로 다시 만들고, 바꾸기 전 보고서와 비교했습니다.

> 여기 숫자는 **가상 플레이어**(`src/sim/player.ts`)의 실패율입니다. 실수 확률을 가정해서 만든 모델이라 레벨끼리 비교하는 데만 쓰고, **실제 이용자 실패율이 아닙니다.**

## 다른 요인이 섞였는지 확인

1. 현재 코드에서 R3만 되돌려(막힌 탭도 폭탄 숫자를 줄임) 보고서를 다시 만들었습니다. 기존에 커밋된 보고서와 **바이트 단위로 같았습니다.**
   그러니 기존 보고서 이후 레벨 데이터, 가상 플레이어, 난수 등 보고서에 영향을 주는 다른 변경은 없습니다.
2. R3를 적용해 다시 만든 보고서에서 바뀐 줄은 **폭탄이 있는 36레벨뿐**입니다. 폭탄이 없는 144레벨은 한 글자도 바뀌지 않았습니다.

따라서 아래 차이는 모두 R3 때문입니다(같은 난수 시드에서 200회씩 돌린 결과라 레벨 하나하나의 숫자에는 표본 오차가 있습니다).

## 결과

설정: 180레벨, 플레이어 유형별 200회, 하트는 레벨 설정 그대로. 재생성 명령 `npx tsx scripts/sim-report.ts`(약 30초).

**폭탄이 있는 36레벨 평균 실패율**

| 플레이어 | 바꾸기 전 | R3 적용 후 |
|---|---|---|
| 신중 | 1.2% | 1.0% |
| 보통 | 21.2% | 16.1% |
| 급함 | 67.7% | 60.3% |

**챕터별 평균 실패율(보통 플레이어)**: 1~4챕터는 그대로(20.0 / 21.6 / 20.4 / 19.0%), 5챕터 18.6% → **13.7%**, 6챕터 19.5% → 18.1%.

- 5챕터가 보통 플레이어 기준으로 가장 쉬운 챕터가 됐습니다(다른 챕터는 19~22%).
- 보통 플레이어 기준 15%p 이상 바뀐 레벨: 140(어려움) 30.0% → 14.5%, 149(일반) 35.5% → 20.5%.
- 5챕터 인접 레벨 간 실패율 차이(보통 플레이어, 연속한 두 레벨의 차이 평균): 9.0%p → 7.3%p.
  [POLISH.md](../POLISH.md) D1의 "6.5%p"와는 계산 방법이 달라 직접 비교할 수 없습니다.

## 이 결과로 하지 않은 것

결정(2026-10-30)에 따라 난이도 보정은 하지 않았습니다. 생성기 여유 탭 3을 유지하고, 폭탄 레벨도 다시 고르지 않았습니다.
5챕터가 쉬워진 것이 실제 플레이에서도 느껴지는지는 이용자 테스트로 확인합니다.
