# UI 시스템 v0.2

게임 화면 UI의 공통 규격이다. 2026-11-04에 확정했다. 규격(색, 버튼, 패널)은 [game/ui.css](../../game/ui.css)에 있고, 화면별 배치는 [game/index.html](../../game/index.html)의 `<style>`에 있다. 2.5D와 Classic 3D가 같은 UI를 쓴다.

## 원칙

- 플레이 화면은 차분하게, 보상 순간(클리어)은 선명하게 한다.
- 한 화면에 핵심 숫자는 1~2개만 둔다.
- **색은 버튼이 하는 일**을, **크기와 입체는 그 화면에서의 중요도**를 나타낸다. 같은 '다시 하기'도 아래 바에서는 보조(입체 4px), 실패창에서는 주 버튼(L, 입체 6px)이다.
- 크림 재질 하나를 모든 패널·칩·보조 버튼에 쓴다. 바탕은 크림 그라데이션, 테두리는 1.5px 황갈색 안쪽선, 받침은 황갈색 단색, 그림자는 따뜻한 갈색이다. 흰 스티커 테두리, 광택 캡, 두꺼운 글자 외곽선은 쓰지 않는다.
- 40~60대 기준으로 글자는 최소 15px, 버튼은 최소 44px이다.

## HUD

- 상시 표시: **레벨 번호**(작은 '레벨' + 큰 숫자, Jua).
- 조건부 표시: **하트**(34px). 하트가 없는 레벨에서는 하트 칸과 구분선이 사라진다.
- HUD에서 뺀 것: 장소 이름(스테이지 시작 배너와 홈 화면에 나옴), 10칸 진행도(결과창으로 옮김).
- 오른쪽 위: 설정 버튼(타이틀과 플레이 공통). 폭탄이 있으면 그 아래에 폭탄 칩이 나온다.

## 결과창 (클리어)

위에서부터 다음 순서로 놓인다.
1. 동물 3마리(고정, `game/public/assets/ui/result/`의 승인된 2.5D 정면 그림 사본)
2. '구출 성공!' 리본
3. '친구 N마리를 구했어요' (N은 그 레벨의 동물 수)
4. 장소 + `+1` + `N / 10` 진행 막대(이번에 채운 칸을 밝게 표시)
5. 다음 레벨(L, primary)
6. 홈으로(M, secondary)

결과창에 넣지 않는 것: 남은 하트(점수처럼 보임), 누적 구출 수(스테이지·챕터 완료 카드에 나옴).

스테이지의 마지막 레벨은 결과창에서 10/10을 보여 준 뒤, '다음 레벨'을 누르면 스테이지 완료 카드가 이어서 뜬다.

## 실패창 · 확인창 · 설정

- **실패창:** 제목(하트 소진은 보라, 폭탄은 주황빨강), '다시 도전해 볼까요?', 하트 소진일 때만 쓴 하트 받침, 다시 하기(L, 파랑), 홈으로.
- **판을 끝낸 탭의 클릭은 결과창·실패창이 무시한다.** 판이 끝나는 순간 뜬 팝업 버튼에 같은 탭이 떨어져 바로 재시작되는 것을 막는다. 새로 누르는 탭, 키보드, 스크립트 클릭은 통과한다.
- **다시 하기 확인:** 다시 하기(L, 파랑), 취소(M, 크림).
- **설정:** 소리 켜짐/꺼짐 토글 하나(`#mute`, 꺼지면 `muted` class, 저장 키 `animal-rescue-muted`)와 닫기(M, 크림). 창이 화면 전체를 덮어서 열려 있는 동안 판은 탭되지 않는다.

## 튜토리얼 (병아리 안내, 2026-11-08)

세 종류를 구분하고 학습 방식은 통일하지 않는다. 그림은 [game/tutorial.ts](../../game/tutorial.ts), 어떤 레벨에 무엇을 띄울지는 [src/game/tutorialPlan.ts](../../src/game/tutorialPlan.ts)와 [game/main.ts](../../game/main.ts)가 정한다.

| 종류 | 레벨 | 조작 | 닫기 |
|---|---|---|---|
| 조작형 | 기본(1), 막힘(2), 화살표(6), 충돌(8), 상자 1금(11), 잠(91) | 눌러야 하는 동물 하나에만 손가락. 그 동물의 자리를 누르면 게임의 탭이 되고, 다른 곳의 터치는 모두 무시 | 그 탭, 또는 건너뛰기 |
| 안내형 | 다이너마이트(40) | 손가락 없음. 대상 동물만 밝게, 숨쉬기와 1.4초마다 펄스 | 말풍선 터치(우하단 `›`). 터치는 판에 닿지 않음 |
| 발견형 | 상자 2금(12) | 손가락 없음. 상자와 이웃 칸만 밝게, 정답 동물을 가리키지 않음 | 말풍선 터치. **닫아도 학습이 아니고**, 상자가 부서질 때 학습 |

- **말풍선·병아리**: 한 규격(`.tutBubble`, `.tutChick`). Jua 21px/1.2, 안쪽 여백 10·18px, 크림 바탕에 1.5px 황갈색 안쪽선, 병아리 96px. 한글은 단어 단위로 줄바꿈하고(`word-break: keep-all`) 긴 문구는 손으로 줄을 나눈다. 안내형·발견형은 오른쪽 여백 36px에 `›`.
- **자리**: 기본은 HUD와 판 윗변 사이 띠의 가운데(`room`). 동물을 가리지 않고, 조작형은 손가락이 대상을 짚는다. 띠가 말풍선보다 16px 이상 높지 않거나 대상이 띠 아래로 420px 넘게 멀면 대상 위·아래 중 넓은 쪽에 붙인다. 결과 순간에는 바뀐 동물 옆으로 간다. 좌표를 레벨별로 두지 않는다.
- **건너뛰기**: 말풍선 오른쪽, 44px, 한 줄(`white-space: nowrap`). 안내형·발견형에는 없다.
- **결과 표시 시간**: 바뀐 동물이 보이면 점등만 0.8초(`RESULT_MS`: 막힘의 막은 동물, 잠에서 깬 동물, 상자가 놓아준 동물). 규칙을 읽어야 하면 말풍선 한 줄과 하단 문구를 1.6초(`BUMP_RESULT_MS`: 충돌). 안내형은 시간 없이 말풍선 터치까지. 화살표는 타일 튕김, 상자 2금은 하단 문구로 대신한다.
