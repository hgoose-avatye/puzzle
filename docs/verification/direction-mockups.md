# 방향 인식 비교 시안 (2026-10-30, 결정 전)

실기기 플레이테스트에서 여러 이용자가 "동물의 앞뒤를 구분하기 어렵다"고 했습니다. 기존 디자인과 세 가지 개선안을 같은 레벨, 같은 카메라(58°), 같은 화면(390×844)에서 비교합니다.
최종안은 아직 정하지 않았고, 기본 게임 화면은 기존 그대로입니다.

## 보는 방법 (개발 서버 전용)

- 비교판: `?demo=dirs&look=base|A|D|E`
  - 위부터 1칸·2칸·3칸 동물이 각각 상·하·좌·우를 봅니다.
  - 아래 두 줄은 붐비는 경우입니다. 바로 앞에 다른 동물이 있거나, 카메라 쪽에 다른 동물이 가리는 상황입니다.
- 실제 레벨: `?level=10&look=base|A|D|E`
- 배포 빌드에서는 `look` 값을 무시합니다. 개발 서버 전용 파라미터라 배포 빌드는 늘 `base`입니다.

## 시안

| | 내용 | 바뀐 것 |
|---|---|---|
| 기존 | 지금 게임. 1칸 동물만 바닥에 옅은 V | — |
| A 머리 실루엣 | 정수리의 귀·털·볏·뿔·더듬이를 앞쪽으로 옮기고 앞으로 기울입니다. 모든 머리에 앞으로 넘어가는 앞머리 세 가닥을 몸 색보다 조금 어둡게 붙입니다 | 머리 위 장식만. 눈·몸 색·크기는 그대로 |
| D 머리·꼬리 실루엣 | 2~3칸은 머리에서 꼬리로 갈수록 좁고 낮아집니다. 1칸은 머리 쪽이 각진 큰 덩어리이고 엉덩이가 작고 둥급니다. 꼬리를 40% 키웁니다 | 몸 비율 |
| E = D + 작은 보조 표시 | D에 정수리 무늬 하나(몸 색보다 어두운 작은 `∧`, 앞쪽을 가리킴)를 더합니다 | 바닥 표시 대신 머리 위 무늬 |

- A·D·E에서는 기존 바닥 V를 뺐습니다. 캐릭터만으로 얼마나 읽히는지 보기 위해서입니다.
- E의 보조 표시를 처음에는 바닥에 두었는데, 동물 몸에 가려 거의 보이지 않았습니다. 그래서 늘 카메라에 보이는 정수리로 옮겼습니다.

## 스크린샷을 보고 확인한 점 (판단은 사용자 비교 후)

- **기존**:
  - 위를 보는 동물은 등만 보여 앞뒤가 같아 보입니다.
  - 좌우를 보는 동물은 좁은 옆면만 보입니다.
  - 2~3칸 동물은 머리 블록과 몸 블록 크기가 거의 같습니다.
- **A**:
  - 귀가 큰 동물(여우, 허스키, 소)은 귀가 앞으로 기울어 차이가 보입니다.
  - 앞머리 덕분에 위를 보는 돼지와 닥스훈트의 머리 쪽이 표시됩니다.
  - 펭귄처럼 어두운 동물은 앞머리가 몸 색에 묻힙니다.
  - 위에서 볼 때 변화가 작아서, 화면 전체 크기에서는 기존과 차이가 크지 않습니다.
- **D**:
  - 2~3칸 동물(악어, 뱀, 소, 돼지, 닥스훈트)은 꼬리 쪽이 좁아져 앞뒤가 가장 분명합니다.
  - 1칸은 둥근 엉덩이가 생겼지만, **둥근 쪽이 오히려 머리처럼 보일 위험**이 있습니다(레벨 10의 노란 병아리).
- **E**:
  - 정수리 `∧`는 초록·주황·분홍처럼 밝은 몸에서는 잘 보입니다.
  - **어두운 회색 동물(펭귄, 허스키)에서는 거의 안 보입니다.**
  - 돼지는 귀와 겹쳐 무늬가 흐려집니다.
- **공통**:
  - 모든 시안이 자기 칸 안에 있습니다.
  - 기존 색과 카메라를 유지했고 큰 화살표는 없습니다.

## 검증 계획(결정 후)

- 고른 시안으로 실기기 체크리스트 D9를 진행합니다. 1칸 동물 10마리의 방향을 누르기 전에 맞히는 테스트이고, 붐비는 경우도 포함합니다.
- 기존 디자인과 같은 방식으로 맞힌 수를 비교합니다.
