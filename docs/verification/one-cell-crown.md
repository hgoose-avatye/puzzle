# D1 vs D2: 머리 윗면 실루엣 비교 (2026-10-30, 결정 전)

붐비는 배치에서 바닥 표시가 가려지는 문제를 바닥 표시만으로 풀지 않기 위해, 늘 보이는 **머리 윗면**을 비교합니다. 붐비는 1칸 동물은 180레벨 시작 시 30.1%입니다([one-cell-cues.md](one-cell-cues.md)).
출시 게임은 그대로이고, 아래 파라미터는 개발 서버에서만 동작합니다.

| 안 | 주소(개발 서버) | 내용 |
|---|---|---|
| D1 | `?look=AD&mark=v2` | AD 디자인 + 진하고 채도 낮은 V(B) |
| D2 | `?look=AD&mark=v2&crown=1` | D1 + 머리 윗면 실루엣 강화. 동물이 원래 가진 머리 특징만 씁니다 |

D2에서 바꾼 것([game/blocks.ts](../../game/blocks.ts) `crownBoost`):

| 동물 | 머리 윗면 |
|---|---|
| 병아리 | 정수리 털을 1.4배로 키우고, 앞쪽 끝에 털 한 가닥을 더해 앞으로 말린 새싹 모양으로 |
| 돼지 | 접힌 귀를 1.3배로 키우고 이마 쪽으로 더 늘어뜨림 |
| 펭귄 | 앞면의 흰 얼굴이 **정수리 앞쪽 가장자리까지 이어지게**(흰 이마 띠). 정수리 털 1.25배. 어두운 머리에서도 앞쪽이 보이게 |
| 허스키 | 얼굴의 흰 줄무늬가 정수리 앞쪽으로 이어지게 |
| 앵무새 | 볏을 1.3배로 키우고 앞으로 더 말림 |
| 그 밖의 동물 | AD 그대로 |

- 큰 화살표, 발광, 외곽선, 새 장식은 쓰지 않았습니다.
- 동물 크기와 타일 점유는 그대로입니다. 몸이 블록 중심에서 닿는 가장 먼 거리는 기존, D1, D2 모두 0.657로 같습니다(비교판 21마리, 테스트판 10마리).
- 카메라 58°, 화면 390×844, 게임 규칙과 터치 판정은 그대로입니다.

## 측정: 머리 윗면과 바닥 V가 화면에 보이는 정도

개발 서버 훅 `crownStats()`, `markStats()`를 씁니다. 표시나 머리 윗면 장식이 차지하는 화면 영역을 1px 간격으로 찍어, 맨 위에 그려진 점과 다른 동물에 가려진 점을 셉니다. 숫자는 "보인 점 / 전체 점"입니다.

| 1칸 동물 | 바닥 V(D1·D2 같음) | 머리 윗면 D1 | 머리 윗면 D2 |
|---|---|---|---|
| 위, 단독 (비교판 #1) | 26/26 | 119/119 | **217/217** |
| 아래, 단독 (#2) | 23/25 | 93/93 | 134/134 |
| 왼쪽, 단독 (#3) | 22/25 | 123/123 | 168/168 |
| 오른쪽, 단독 (#4) | 19/23 | 110/110 | 204/204 |
| **위, 카메라 쪽에 다른 동물 (#13)** | **0/32** | 131/131 | **195/195** |
| **아래, 카메라 쪽에 다른 동물 (#18)** | **0/36** | 138/138 | **214/214** |
| 위, 옆이 붐빔 (#21) | 27/31 | 147/147 | 296/296 |
| 테스트판: 위, 펭귄 단독 (#1) | 41/41 | 184/184 | **366/366** |
| **테스트판: 아래, 펭귄, 카메라 쪽에 병아리 (#4)** | **0/51** | 191/191 | **416/416** |
| **테스트판: 위, 병아리, 붐빔 (#5)** | **0/55** | 191/191 | **302/302** |

- **머리 윗면은 모든 경우에 100% 보이고, 다른 동물에 가려진 점은 0입니다.** 바닥 V가 0%가 되는 붐비는 경우도 포함합니다.
- 뒤 칸 동물의 머리 윗면은 앞 동물보다 화면에서 위에 그려지므로 가려지지 않습니다.
- D2의 머리 윗면 장식은 D1보다 화면에서 **약 1.4~2.2배 넓습니다.**
- 이 측정은 "보이는가"만 잽니다. "방향이 읽히는가"는 아래 스크린샷 판단과 이용자 테스트로 봅니다.

## 스크린샷으로 본 점

- **펭귄(어두운 동물)**: D2의 흰 이마 띠가 정수리 앞쪽 가장자리에 또렷이 보입니다.
  - 위를 보면 먼 쪽 끝, 오른쪽을 보면 오른쪽 끝에 보이고, 붐빌 때도 보입니다.
  - 네 방향 모두에서 앞쪽이 가장 분명하게 달라진 동물입니다.
  - 다만 띠의 모서리가 각져 있어 **납작한 흰 스티커처럼 보입니다.** 모서리를 둥글게 하거나 얼굴 쪽과 곡선으로 이어지게 다듬을 여지가 있습니다.
- **병아리, 앵무새**: 털과 볏이 커지고 앞으로 더 기울었습니다. 하지만 정수리 가운데 근처에 있어 위에서 보면 앞뒤 차이가 여전히 작습니다.
- **돼지(2칸 머리)**: 커진 귀가 이마 쪽으로 늘어져 머리 쪽이 보입니다.
- **허스키**: 흰 줄무늬가 화면에서는 거의 드러나지 않습니다.
- **귀여움**:
  - 눈, 부리, 볼터치 같은 얼굴과 색, 비율은 그대로라 전체 인상은 유지됩니다.
  - 펭귄의 흰 띠가 가장 눈에 띄는 변화인데, 펭귄의 원래 흰 얼굴이 이어진 모습이라 캐릭터 안에서 읽힙니다.

## 정리

| | D1 (AD + 진한 V) | D2 (D1 + 머리 윗면) |
|---|---|---|
| 단독 1칸 | V가 보이고 방향을 알려 줌 | V와 머리 윗면이 함께 방향을 알려 줌 |
| 붐비는 1칸(시작 시 30%) | V가 가려져 **방향 단서가 AD의 작은 머리 장식뿐** | 머리 윗면 장식이 늘 보이고 D1보다 넓음 |
| 어두운 1칸(펭귄) | 머리 장식이 몸 색에 묻힘 | 흰 이마 띠로 앞쪽이 또렷 |
| 밝은 1칸(병아리, 앵무새) | 작은 머리 장식 | 장식이 커졌지만 앞뒤 차이는 여전히 작음 |
| 귀여움 | 유지 | 유지. 펭귄 흰 띠는 모양 다듬을 여지 |
| 크기·점유·규칙·터치 | 그대로 | 그대로 |

- 화면 측정과 스크린샷으로 보면 **D2가 붐비는 경우와 어두운 동물에서 D1보다 낫습니다.**
- 밝은 1칸 동물(병아리, 앵무새)의 앞뒤 구분은 D2에서도 충분하다고 단정할 수 없습니다.
- 실제로 더 잘 맞히는지는 [방향 맞히기 테스트](direction-test.md)로 확인합니다. 테스트판 `?demo=quiz`에 위 파라미터를 붙여 D1과 D2를 비교합니다.
