# 1칸 동물 방향 표시 비교 (2026-10-30, 결정 전)

2~3칸은 AD를 유력 후보로 두고, 1칸 동물의 방향 표시만 세 가지로 비교합니다. 카메라는 58°입니다.
출시 게임은 그대로이고, 아래 파라미터는 개발 서버에서만 동작합니다.

| 안 | 주소(개발 서버) | 1칸 동물 | 바닥 표시 |
|---|---|---|---|
| A | `?look=AD&one=base&mark=v` | 지금 모델 | 지금의 옅은 V(동물 색을 흰색 쪽으로 50%, 두께 0.045칸) |
| B | `?look=AD&mark=v2` | AD | 같은 자리, 같은 모양의 V를 **동물 색에서 어두운 회색 쪽으로 60%** 낮추고 두께 0.065칸으로 조금 굵게. 채도가 낮고 외곽선·발광·그림자 없음 |
| C | `?look=AD&mark=edge` | AD | 타일 **앞쪽 가장자리**를 따라 놓은 문턱 모양 막대(B와 같은 색). 가운데에 작은 홈이 바깥(진행 방향)을 가리킴 |

- 세 안 모두 2~3칸 동물은 AD이고, 표시는 자기 타일 안에만 있습니다.
- A·B의 V 위치는 지금 게임과 같습니다.
  - 아래를 보면 앞 가장자리, 좌우를 보면 앞 가장자리의 카메라 쪽 끝에 놓입니다.
  - 위를 보면 카메라 쪽 가장자리에 놓고 꼭짓점이 위를 가리킵니다.

## 측정: 표시가 화면에 보이는 비율

개발 서버 훅 `window.__game.markStats()`로 표시가 차지하는 화면 영역을 1px 간격으로 찍었습니다. 맨 위에 그려진 점(보임)과 동물에 덮인 점(가려짐)을 셉니다. 화면 390×844이고, 숫자는 "보인 점 / 표시 전체 점"입니다.

| 1칸 동물 (방향 비교판, 테스트판) | A | B | C |
|---|---|---|---|
| 위, 주변 비어 있음 (#1) | 17/17 | 26/26 | **0/36** |
| 아래, 주변 비어 있음 (#2) | 15/17 | 23/25 | 57/57 |
| 왼쪽, 주변 비어 있음 (#3) | 15/17 | 21/25 | 30/49 |
| 오른쪽, 주변 비어 있음 (#4) | 14/17 | 19/23 | 14/49 |
| 위, **카메라 쪽(아래 칸)에 다른 동물** (#13, 테스트판 #5) | **0** | **0** | **0** |
| 아래, **카메라 쪽에 다른 동물** (#18, 테스트판 #4) | **0** | **0** | **0** |
| 왼쪽, 앞에 다른 동물 (#20) | 19/23 | 27/33 | 37/68 |
| 위, 옆이 붐빔 (#21) | 24/25 | 27/31 | **0/66** |

- **C는 위를 보는 동물에서 늘 0%입니다.** 1칸 동물은 높이가 약 1.1칸입니다. 58°에서 몸 뒤로 약 0.7칸의 바닥이 가려지므로, 위를 볼 때의 앞 가장자리(먼 쪽)는 자기 몸에 가려집니다. 좌우를 볼 때도 앞 가장자리의 상당 부분이 몸 옆면 아래에 들어가 29~61%만 보입니다.
- **A와 B는 같은 위치라 가려지는 경우가 같고, B가 더 진해서 보이는 점이 많습니다.** 스크린샷에서도 A의 옅은 V는 노란·연두 바닥판에서 잘 안 보이고, B의 진한 V는 또렷합니다.
- **세 안 모두, 카메라 쪽 바로 아래 칸에 다른 동물이 있으면 0%입니다.** 앞 동물의 몸이 뒤 칸 바닥 대부분을 덮기 때문입니다(POLISH F8과 같은 원인). 바닥에 놓는 표시라면 모양이나 색을 바꿔도 피할 수 없습니다.

### 실제 레벨에서 얼마나 자주 가려지나

180레벨의 시작 상태에서 1칸 동물은 804마리입니다. 그중 **바로 아래 칸(카메라 쪽)에 다른 동물이 있는 것은 242마리(30.1%)**입니다.
방향별로는 위 27.2%, 아래 28.5%, 왼쪽 30.6%, 오른쪽 34.2%입니다. 판이 비어 갈수록 줄어들지만, 시작할 때는 1칸 동물 셋 중 하나꼴로 바닥 표시가 보이지 않습니다.

## 정리

| | A 지금 V | B 진한 V | C 앞 가장자리 문턱 |
|---|---|---|---|
| 위를 볼 때 | 보임(옅음) | 보임(또렷) | **안 보임**(자기 몸) |
| 좌우를 볼 때 | 보임(옅음) | 보임(또렷) | 일부만 |
| 카메라 쪽에 다른 동물(시작 시 30%) | 안 보임 | 안 보임 | 안 보임 |
| 캐릭터·귀여움 | 그대로 | 그대로, 표시가 조금 진해짐 | 그대로 |

- 바닥 표시 안에서는 **B가 A보다 낫고, C는 위를 보는 동물에서 쓸 수 없습니다.**
- 어떤 바닥 표시도 붐빌 때(시작 시 1칸의 약 30%)는 보이지 않습니다.
  - 붐빌 때도 늘 보이는 것은 **동물의 머리 윗면**입니다. 뒤 칸 동물의 윗면은 앞 동물보다 높이 보입니다.
  - 그래서 붐비는 경우까지 해결하려면 바닥 표시와 함께, AD의 머리 위 모양(앞으로 기운 장식과 앞머리)이 1칸에서도 더 또렷해야 합니다.
- 이 판단은 화면 측정에 근거합니다. 실제로 더 잘 맞히는지는 [방향 맞히기 테스트](direction-test.md)로 확인합니다. 테스트판 주소 뒤에 위 안의 파라미터를 붙이면 됩니다.

## 결정 (2026-10-30)

- **C(타일 앞쪽 가장자리 표시)는 최종 후보에서 제외합니다.** 위를 보는 동물에서 늘 자기 몸에 가려집니다(0%).
- **B(진하고 채도 낮은 V)는 보조 표시 후보로 유지합니다.** 보이는 상황에서는 A보다 또렷합니다.
- **B의 한계**: B도 바닥에 놓이는 표시입니다.
  - 카메라 쪽 바로 아래 칸에 다른 동물이 있으면 **완전히 가려져 효과가 없습니다**. 측정에서 0%였고, 180레벨 시작 시 1칸 동물의 30.1%가 이 경우입니다.
  - 그래서 B만으로는 1칸 방향 문제를 해결할 수 없습니다. 붐비는 경우는 머리 윗면 모양으로 보완해야 합니다([one-cell-crown.md](one-cell-crown.md)).
