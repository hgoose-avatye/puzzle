# P0-7 실기기 플레이 체크리스트

iOS Safari와 Android Chrome 실기기에서 손으로 확인하는 목록입니다. 기대 동작의 기준은 [규칙 명세](../rules.md)입니다.
헤드리스 검증(`npm run test:e2e`)이 통과해도 실기기에서는 터치 지연, 두 손가락 처리, 화면 크기가 다를 수 있어 따로 확인합니다.

**상태 값**: `PASS`(예상대로) / `FAIL`(다름, 실제 결과에 무엇이 달랐는지 적기) / `미실행`. 처음에는 모두 `미실행`입니다.
FAIL이면 가능하면 화면 녹화나 스크린샷을 남기고 파일 이름을 실제 결과 칸에 적습니다.

## 준비

1. PC에서 게임 서버를 같은 Wi-Fi에 열어 둡니다.
   ```bash
   npx vite --config vite.game.config.ts --host
   ```
   출력에 나온 `Network: http://<PC 주소>:5200/` 주소를 폰에서 엽니다.
2. 장면은 주소 뒤에 붙여 엽니다.
   - `?demo=cross`: 9×9 판, 동물 4마리, 하트 3
     - 1: 몸 3칸, 오른쪽으로 감
     - 2: 위쪽 가운데, 아래로 감. 1이 지나가는 줄을 가로지름
     - 3: 오른쪽 아래, 위로 감
     - 4: 2 바로 위, 2에 막혀 있음
   - `?demo=bomb`: 같은 판에서 2가 폭탄(숫자 2)
   - `?level=N`: 실제 레벨 N
3. 처음 열 때 규칙 설명 팝업이 뜨면 "시작!"을 누릅니다.
4. 소리는 첫 터치 뒤에 켜집니다. 무음 모드를 끄고 확인합니다.
