# 악어 2.5D 실험 결과 (2026-11-01, 완료)

브랜치 `experiment/2-5d-sprites`, 커밋하지 않음. 기존 게임 코드는 바꾸지 않음.

## 결론

3칸 악어를 3D 모델 없이 HTML·CSS·TypeScript·Canvas 2D와 PNG 스프라이트로 그려, 게임 규칙 그대로 움직이고 꺾이고 탈출하게 할 수 있다. 사용자가 시각 검증 통과로 판단했다(2026-11-01).

## 확정 사항

| 항목 | 내용 |
|---|---|
| 그림 | 머리 5장, 몸통 3장(0°·45°·90°), 꼬리 5장. 나머지 방향은 좌우 반전·앞뒤 대칭 (`assets/crocodile/*-approved/`, 읽기 전용, SHA256SUMS) |
| 그리기 | 8방향, 블록마다 0.10칸 겹침(잠정), 화면 깊이 순서 |
| 규칙 | 게임과 동일 (경로·막힘·탈출·하트) |

## 공통 렌더러 연결 (2026-11-01)

- **연결:** 프로토타입 기본 렌더러를 `src/sprites.ts` + `src/spriteRender.ts` + 매니페스트로 교체했습니다. `?render=legacy`로 예전 렌더러를 볼 수 있습니다.
- **병아리 (1칸):**
  - 기존 렌더러와 모든 프레임에서 사실상 같습니다. 직선 4방향과 달리면서 꺾기, 390·360 모두 확인했고, 차이가 가장 큰 프레임도 16px에 차이 12 이하라 안티앨리어싱 수준입니다.
  - 방향 선택 시점이 어긋나는 문제를 발견해 고쳤습니다. 8방향으로 먼저 반올림하던 것을 연속 각도 기준으로 바꿨습니다.
- **2칸 (시험 매니페스트, 악어 머리+꼬리):** 직선과 90° 꺾기를 확인했습니다. 그림 누락 0, 탈출 정상입니다.
- **악어 (3칸):** 직선 4방향, 꺾기, 연속 꺾기, 계단, 병아리와 함께 있는 장면을 확인했습니다. 그림 누락 0, 탈출 정상입니다.
- **테스트:**
  - 게임 209/209

  - 프로토타입 장면 검사 40/40 (공통 렌더러로 실행)
