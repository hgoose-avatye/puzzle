# 작은 통매듭 퍼즐 실험 (2026-11-07)

**질문**: 6×8 판에 동물 6~9마리를 전부 얽어 놓으면 "판 전체가 하나의 추론 문제"로 작동하는가.

## 플레이 방법

개발 서버(이 워크트리, 포트 5436)에서, 저장·180레벨을 건드리지 않는 개발 전용 URL:

| 판 | URL | 출처 |
|---|---|---|
| easy | `http://192.168.0.23:5436/?exp=easy` | 손 설계 |
| gen1 | `…/?exp=gen1` | 생성기 (`make.ts 1 8 4 300 2`, 시드 4) |
| gen2 | `…/?exp=gen2` | 생성기 (`make.ts 2 8 4 2000 3 6`, 시드 4) |
| gen3 | `…/?exp=gen3` | 생성기 (같은 조건, 시드 1) |
| gen4 | `…/?exp=gen4` | 생성기 (`make.ts 3 9 1 2000 3 7`, 시드 1) |
| 비교용 8×12 | `…/?level=70&dev`, `…/?level=130&dev` | 현재 180판 |

규칙·되돌리기(3번)·막힘 안내는 본 게임과 같다. 판마다 "걸린 시간 / 다시 하기 / 읽어서 풀었나·눌러서 풀었나"를 적어 주면 결론이 나온다.

## 각 판의 의도한 추론 구조 (`CHECK.txt`가 솔버 검증 전문)

**easy (손, 8마리, 전부 매듭)** — 고리: 1은 2의 꼬리에 막히고, 3은 1에, 4는 3에, 5는 4의 꼬리에, 8은 5에, 7은 8에, 6은 7에, 2는 6에 막힌다. 움직일 수 있는 건 1·5·6뿐.
- 1을 밀면(오른쪽으로 3칸, 2 앞까지) 3이 풀리고 3→4→5→8→7→6→2→1 순서로 전부 나간다. **정답.**
- 6을 밀면 5·7·8이 만든 ㄱ자 안으로 들어가 네모를 닫는다: 넷이 서로 막혀 영원히 못 나간다. 밀자마자 판이 멈추므로 **보이는 함정**.
- 5를 밀면 한 칸 올라갈 뿐 아무것도 안 바뀐다(낭비, 손해 없음).
- 솔버: 풀이 가능, 정답 밀기 1, 강제 밀기 0(5가 "해롭지 않은 선택지"라 지표상 강제가 아님), 정답 가짓수 3.

**gen1 (8마리, 전부 매듭)** — 두 번 밀기. 6(아래)을 한 칸 밀어 3의 길을 비우는 게 핵심이고, 2를 먼저 오른쪽 끝까지 보내 두면 나머지가 순서대로 풀린다. 7·8을 밀면 한 칸 움직이지만 서로의 길을 막아 나중에 멈춘다(숨은 함정 2개). 강제 밀기 1, 정답 2.

**gen2 (8마리, 6마리 매듭)** — 세 번 밀기(7 → 3 → 4), 중간에 7이 나간다. 강제 밀기 1, 정답 4.

**gen3 (8마리, 6마리 매듭)** — 4가 먼저 나가고, 2 → 8 → 7 세 번 밀기. 강제 밀기 1, 정답 5.

**gen4 (9마리, 7마리 매듭)** — 6이 먼저 나가고, 1 → 7 → 5 세 번 밀기. 강제 밀기 1, 정답 3.

## 실측

- 생성+탐색 시간: 6×8에서 후보 하나(탐색 300회) 0.15~0.3초, 2,000회 0.7~3초. 채점 한 번 0~2ms. 8×12의 400~1000ms/회와 비교하면 수백 배 빠른 건 맞다 — 그러나 아래처럼 깊이가 안 나온다.
- **깊이**: 전부 매듭(knotMin = 동물 수)이면 탐색 2,000회로도 강제 밀기 0(6·7마리) — 판이 꽉 차서 움직일 수 있는 동물이 1~2마리뿐이라 갈림길이 없다. 1~2마리를 자유롭게 두어야(knotMin 6/8, 7/9) 강제 밀기 1이 나오고, 2 이상은 어느 설정에서도 안 나왔다.
- **손 설계**: easy의 고리는 됐으나, 거기에 두 번째 결정을 결합하려는 시도는 모두 실패했다 — 같은 줄에서 마주 보는 두 동물(영원히 못 품)이 되거나, 새 동물이 그냥 나가 버리는(장식) 둘 중 하나. 이 규칙에서 "틀린 밀기"가 치명적이 되려면 밀린 동물이 멈춘 자리가 새 순환을 만들어야 하는데, 작은 판에서는 그 자리가 거의 없다.

## 이 실험이 말해 주는 것

가설("판이 작고 전부 얽히면 판 전체가 추론 문제가 된다")은 **반만 맞다**. 전부 얽힌 작은 판은 읽을 것이 적어 결정이 1개로 줄고, 깊이는 오히려 **빈 공간**(동물이 달려가 멈출 자리)에서 나온다. 즉 "장식 동물"로 보였던 자유 동물과 빈 칸이 깊이의 재료였다. 다음 질문은 "매듭 6~9마리 + 빈 공간"을 8×12보다 작은 판(예: 7×10)에서 어떻게 배치하느냐이지, 통매듭이 아니다.
