# 스테이지 배경 그림

스테이지마다 그림 한 장을 판 아래에 깐다(`game/stage.ts`의 `BG_SLUGS`). 이 폴더에 아래 이름으로 넣으면 그 스테이지가 저절로 그림 배경이 되고, 3D 소품과 화면 위·아래 흐림(틸트시프트)이 빠진다. 그림이 없는 스테이지는 지금처럼 3D 소품을 쓴다.

| 챕터 | 1스테이지 (1~10) | 2스테이지 (11~20) | 3스테이지 (21~30) |
|---|---|---|---|
| 동물 마을 `village` | 꽃밭 `village-flower` ✅ | 농장 `village-farm` ✅ | 마을 광장 `village-plaza` ✅ |
| 숲속 `forest` | 캠핑장 `forest-camp` ✅ | 강가 `forest-river` ✅ | 깊은 숲 `forest-deep` ✅ |
| 해적섬 `pirate` | 해변 `pirate-beach` ✅ | 항구 `pirate-harbor` | 보물 동굴 `pirate-cave` ✅ |
| 정글 `jungle` | 밀림 입구 `jungle-gate` ✅ | 폭포 `jungle-falls` ✅ | 고대 유적 `jungle-ruins` ✅ |
| 유령 성 `haunted` | 호박밭 `haunted-pumpkin` ✅ | 묘지 `haunted-grave` ✅ | 성 마당 `haunted-castle` ✅ |
| 겨울 마을 `winter` | 눈 마을 `winter-town` ✅ | 얼음 호수 `winter-lake` ✅ | 크리스마스 광장 `winter-xmas` ✅ |

`pirate-harbor`(항구)만 아직 그림이 없어 3D 소품을 쓴다. `alt/`에는 같은 스테이지의 다른 후보가 있다(빌드에 안 들어감). 바꾸려면 `alt/` 파일을 위 이름으로 바꿔 이 폴더에 넣는다.

## 그림 규격

- 정사각형 1:1. 1254px로도 되지만 2048px이 더 또렷하다. `.webp`(품질 90 정도, 장당 약 250KB)로 넣는다. `.png`, `.jpg`도 읽는다.
- 위에서 조금 비스듬히 내려다본 그림. 위쪽 가장자리에 볼거리, 가운데부터 아래쪽은 넓고 평평한 빈 땅(판이 올라간다).
- 그림은 가로 20칸, 세로는 1.4배로 늘려 깐다(비스듬한 그림을 바닥에 눕히면 카메라 때문에 세로로 눌려 보여서). 그림 밖은 그림 아래 가장자리 색으로 이어진다.
- 조명을 받지 않고 그린 색 그대로 나온다.

## 후보 그림 시험

`game/public/assets/bg/`에 넣고 주소에 `?bg=파일명`을 붙이면 어느 스테이지에서나 그 그림을 깔아 볼 수 있다(개발용). `?bgsize=`(가로 칸 수, 기본 20), `?bgstretch=`(세로 배율, 기본 1.4), `?bgy=`(그림을 먼 쪽으로 미는 비율, 기본 0)로 맞춰 본다. 그 폴더는 빌드에 그대로 들어가니 다 쓴 후보는 지운다.
